# FinTrack

FinTrack is an offline-first personal expense tracking Android application built with modern Android development tools.

## Features

- Track income and expenses
- Custom categories
- Dashboard
- Reports
- Material 3 UI
- Offline support

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Hilt
- Room
- Coroutines
- Flow
